Java Backend Practice Lab
This repository is a personal Java backend development practice lab.

The goal of this repo is to practice Java and Spring Boot concepts through structured, ChatGPT-prompted exercises. Each branch focuses on one specific topic. The exercises are generated by ChatGPT, but all implementation is done by hand.

This repo is not meant to be a finished application from the beginning. It is meant to show consistent learning, practice, refactoring, and improvement over time.

How this repository works
Each branch follows this pattern:

A topic is selected, such as object modeling, collections, streams, annotations, or Spring Boot.
ChatGPT provides starter instructions and practice tasks.
I implement the solution manually.
I commit my progress exercise by exercise or milestone by milestone.
Later branches build on concepts learned in earlier branches.
The goal is not to copy finished solutions, but to understand and implement the code myself.
